# ROADMAP.md

Planned features. The self-hosted core is free and open-source — every widget,
connector, layout, rotation, and pairing feature lives here. Each item below has
a tracking issue.

## Widgets
- **Finance / markets** — price, daily change, 24h sparkline. ([#10](https://github.com/fberrez/quietdash.com/issues/10))
- **Homelab / Pi-hole** — queries blocked, blocked-vs-allowed, top domains. ([#11](https://github.com/fberrez/quietdash.com/issues/11))
- **GitHub stats** — contribution grid, open PRs, stars. ([#12](https://github.com/fberrez/quietdash.com/issues/12))
- **Countdown to date** — days until a target. ([#13](https://github.com/fberrez/quietdash.com/issues/13))
- **Year / life-in-weeks progress** — signature 1-bit progress piece. ([#14](https://github.com/fberrez/quietdash.com/issues/14))
- **Quote / word of the day** — local list or feed. ([#15](https://github.com/fberrez/quietdash.com/issues/15))
- **Big metric / habit** — one self-logged number. ([#16](https://github.com/fberrez/quietdash.com/issues/16))

## Connectors
- **Google Calendar (OAuth)** — beyond the public-ICS-URL path. ([#17](https://github.com/fberrez/quietdash.com/issues/17))
- **Transit / departures** — next departures for a stop. ([#18](https://github.com/fberrez/quietdash.com/issues/18))

## Device / reliability
- **Offline image cache** — keep last good image when the server is unreachable. ([#19](https://github.com/fberrez/quietdash.com/issues/19))
- **Partial e-ink refresh** — flicker-free updates for ticking widgets. ([#20](https://github.com/fberrez/quietdash.com/issues/20))
- **Push/webhook refresh** — server-signalled refresh instead of poll-only. ([#24](https://github.com/fberrez/quietdash.com/issues/24))

## Studio / editor
- **Free-form layout editor** — drag/resize grid beyond the fixed layouts. ([#21](https://github.com/fberrez/quietdash.com/issues/21))
- **Templates + import/export** — ready-made starters; share as JSON. ([#22](https://github.com/fberrez/quietdash.com/issues/22))
- **Dashboard duplication** — copy-to-new. ([#23](https://github.com/fberrez/quietdash.com/issues/23))
- **Custom fonts / theming** — limited choices within the 1-bit constraint. ([#25](https://github.com/fberrez/quietdash.com/issues/25))
- **Household / two-board setup** — first-class UX for a couple/family on two devices. ([#26](https://github.com/fberrez/quietdash.com/issues/26))
